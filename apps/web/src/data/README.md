# Summit data

`wainwrights.json` contains 214 Wainwright fell locations derived from the
[Database of British and Irish Hills](https://www.hills-database.co.uk/),
version 17.4.

Source dataset:
[thomaswilsonxyz/wainwright-peaks](https://github.com/thomaswilsonxyz/wainwright-peaks)

The data is available under the
[Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/).

The completion values are temporary prototype state and are not part of the
source dataset.

`ethels.json` contains the 95 Ethels, with heights and OS grid references from
the [Wikipedia List of Ethels](https://en.wikipedia.org/wiki/List_of_Ethels)
under CC BY-SA. Grid references were converted to WGS84 coordinates using the
MIT-licensed `geodesy` package. The Ethels are also recognised by the Database
of British and Irish Hills.

`uk-hills.json` contains area-filtered Nuttalls, Hewitts, Humps, Munros,
Corbetts, Grahams, Donalds and Dillons from the Database of British and Irish
Hills v17.4, licensed under CC BY 4.0. The source file is distributed by the
DoBIH and mirrored in the `thomaswilsonxyz/wainwright-peaks` repository.
